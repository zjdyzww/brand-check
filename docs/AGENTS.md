# AGENTS.md

## Purpose

This site sells one thing: a name screen. Five candidate names in, five verdicts out, each with the status code it rested on.

## How to use it

1. Send one name for free — see the contact section below.
2. If the sample is useful, pay 10 USDC and send up to five names.
3. Receive a Markdown report within 24 hours, one section per name, with the basis for every row and the command to reproduce it.

## Constraints agents should know

- Every verdict is one of `available`, `taken`, `could-not-confirm`. The third is not a failure; it means a register blocked an automated read.
- This is not trademark clearance and not legal advice.
- The tool is open source, so any claim on this site can be re-run rather than trusted: https://github.com/zjdyzww/brand-check
